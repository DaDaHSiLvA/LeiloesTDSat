# LeiloesTDSat

## Descrição do Projeto
O **LeiloesTDSat** é um sistema desenvolvido em Java para a gestão de leilões e controlo de produtos. O sistema permite o cadastro de novos itens, a listagem dos produtos disponíveis e o acompanhamento dos respetivos estados de venda, garantindo a persistência dos dados através da integração com banco de dados.

Projeto desenvolvido para fins académicos como parte das atividades da **UC11** do curso **Técnico em Desenvolvimento de Sistemas**.

## Tecnologias Utilizadas
* **Java**
* **Java Swing** (Interface Gráfica)
* **MySQL** (Banco de Dados relacional)
* **JDBC / MySQL Connector** (Driver de conexão à base de dados)
* **Git e GitHub** (Controlo de versão e hospedagem do código)
